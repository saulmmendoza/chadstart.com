# ChadStart

> YAML-first Backend as a Service — define your entire backend in a single YAML file.

ChadStart auto-generates a fully functional backend — REST API, JWT authentication, Admin UI, realtime subscriptions, OpenAPI docs, file storage, and a plugin system — from one `chadstart.yaml` file.

📖 **[Full documentation](https://saulmmendoza.github.io/chadstart.com/)**

## Quick Start

```bash
npm install
npx chadstart dev
```

Create a `chadstart.yaml` and start building. See the [docs](https://saulmmendoza.github.io/chadstart.com/) for the full schema reference.
