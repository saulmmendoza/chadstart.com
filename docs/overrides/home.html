Get started in seconds

1

Create your project

npx chadstart my-project --cursor
Replace --cursor with --copilot, --windsurf, or omit entirely.
2

Start the server

cd my-project && npm run start
Admin panel at http://localhost:3000  ·  REST API at /api
3

Edit chadstart.yaml and ship

npm run deploy
Deploy to any Node.js host or Docker container.

Everything your backend needs

🧠

Zero friction setup

One command to scaffold a project. One YAML file to define everything. No sprawling config directories.

🔑

Authentication built-in

Mark any entity as authenticable: true to get register, login, and JWT-based auth routes instantly.

📊

Admin panel included

A full-featured admin UI is generated from your schema — browse, create, update, and delete records out of the box.

🚀

REST API in seconds

Full CRUD REST endpoints are automatically generated for every entity. No boilerplate, no glue code.

🤖

LLM-friendly

Plain YAML is easy for AI coding assistants to read and generate. Ship faster with Cursor, Copilot, or Windsurf.

💻

Runs anywhere

Deploy to any Node.js host, use Docker, or run locally. Lightweight enough for a side project, solid enough for production.

🗂️

File & image uploads

Add image or file field types to get upload endpoints with optional S3 storage support.

⚡

Realtime & webhooks

Built-in WebSocket support and webhook triggers let you react to data changes in real time.

🔌

Custom endpoints

Drop a .js file in your functions folder and wire it to any HTTP route in your YAML — full Express power, zero config.

🛡️

Access policies

Control who can read, create, update, or delete each entity with a simple policy array — public, restricted, or admin-only.

✅

Validation

Add field-level validation rules in YAML — min/max length, regex, required, and more. Invalid requests are automatically rejected.

🌊

Rate limiting

Protect your API from abuse with configurable rate limits. Set windowMs and max with two lines of YAML.

☁️

S3 storage

Plug in any S3-compatible provider for file uploads with a few environment variables. Works with AWS, Cloudflare R2, and more.

🔀

Middlewares

Inject custom logic before or after any route. Great for logging, request transformations, or custom auth flows.

👥

Groups

Assign users to groups to implement role-based access control. Define which groups can access which entities and operations.

🔐

Security hardening

Helmet.js headers, CORS configuration, JWT secrets, and bcrypt password hashing — security best practices out of the box.

📡

OpenTelemetry

Built-in observability with OpenTelemetry. Send traces and metrics to any OTLP-compatible backend like Grafana or Datadog.

🗝️

API keys

Generate and manage API keys per entity. Control per-key permissions: create, read, update, delete for each collection.

⌨️

CLI

The chadstart CLI scaffolds new projects in seconds, pre-configured for your favorite AI coding assistant.

🧩

Plugins

Extend ChadStart with community or custom plugins. Add new field types, routes, or behaviors without forking the core.

⚛️

Framework integrations

Official guides and SDK helpers for React, Vue, Angular, Svelte, and Astro. Drop in and start calling your API immediately.
